# tango-saphana

scadawire/tango-controls integration to Profibus Dp Servers

# Structure

The integration makes use of the tango python binding to implement device driver functionality.
See also https://tango-controls.readthedocs.io/en/latest/development/device-api/python/index.html

The Profibus DP specific functionality is covered by the pyprofibus python package.
See also https://pypi.org/project/pyprofibus/
